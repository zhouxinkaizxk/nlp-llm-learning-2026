列表推导式（List Comprehension）总结
作用： 用简洁的写法创建列表。
1. 基本语法
[表达式 for 变量 in 可迭代对象]



例如：
[x ** 2 for x in range(1, 6)]



结果：
[1, 4, 9, 16, 25]



2. 带条件筛选
[表达式 for 变量 in 可迭代对象 if 条件]



例如：
[x for x in range(10) if x % 2 == 0]



结果：
[0, 2, 4, 6, 8]



3. 等价于普通 for 循环
result = []for x in range(1, 6):    result.append(x ** 2)



等价于：
result = [x ** 2 for x in range(1, 6)]



4. 记住各部分的作用
- for：遍历元素。
- if：筛选满足条件的元素。
- 最前面的表达式：决定放入列表的内容。
- []：表示最终生成一个列表。
核心记忆：列表推导式就是把 for 循环、条件判断和 append() 操作简洁地组合起来。
